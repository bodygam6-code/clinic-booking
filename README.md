# 🩺 صفحة حجز العيادة — QR Code + n8n Webhook

صفحة حجز يفتحها العميل من QR Code، يملأ بياناته، والبيانات تتبعت لـ n8n على شكل Webhook.

## 📁 الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | هيكل صفحة الحجز (HTML) — الملف الرئيسي اللي بيفتح من اللينك |
| `styles.css` | تنسيقات صفحة الحجز |
| `app.js` | منطق صفحة الحجز: التحقق من البيانات + الإرسال للـ Webhook |
| `qr.html` | هيكل صفحة توليد الـ QR Code |
| `qr.css` | تنسيقات صفحة الـ QR |
| `qr.js` | توليد الـ QR تلقائيًا من لينك `index.html` |
| `README.md` | الملف ده |

> 📌 لازم الملفات كلها تكون في نفس الفولدر — وارفع الفولدر كامل على الاستضافة.

## 📋 الحقول اللي العميل يملأها

- الاسم بالكامل
- رقم الموبايل (اتحقق منه: 11 رقم يبدأ بـ 01)
- تاريخ الحجز (مش بيقبل تاريخ في الماضي)
- العمر (من 0 لـ 120)
- النوع (ذكر / أنثى)
- العنوان

## 🚀 خطوات التشغيل

### 1) ارفع الصفحة على الإنترنت
الـ QR Code محتاج لينك حقيقي على الإنترنت عشان أي موبايل يفتحه. أسهل طرق (مجانية):

**Netlify Drop (الأسهل):**
1. افتح https://app.netlify.com/drop
2. اسحب فولدر فيه الملفات كلها — هيديك لينك فورًا.

**أو GitHub Pages:**
1. اعمل repo جديد، ارفع الملفات.
2. Settings ← Pages ← فعّل من فرع `main`.

### 2) فعّل الـ Webhook في n8n
1. اعمل Workflow فيه نود **Webhook**:
   - Method: **POST**
   - Path: مثلًا `clinic-booking`
2. انسخ رابط الـ **Production URL** (شكله:
   `https://YOUR-N8N-SERVER/webhook/clinic-booking`)
3. افتح `app.js` وفي قايمة `WEBHOOK_URLS` هتلاقي رابطك — وزيادة رابط زميلك ببساطة:
   ```js
   const WEBHOOK_URLS = [
     "https://YOUR-N8N-SERVER/webhook/clinic-booking",   // بتاعك
     "https://TEAMMATE-N8N-SERVER/webhook/clinic-booking", // بتاع زميلك
   ];
   ```
   كل حجز بيتاخد على كل الروابط اللي في القايمة — ولو واحد فيهم مش شغال، الحجز بيوصل للباقيين عادي.
4. ارفع الملفات تاني بعد التعديل.

> 💡 **CORS:** n8n بيسمح بكل المواقع (origins) افتراضيًا في نود الـ Webhook،
> فغالبًا مش هتحتاج تعمل حاجة. لو ظهرت مشكلة إرسال من المتصفح بس،
> فعّل **Allowed Origins (CORS)** واكتب فيها `*` من: Options ← Add Option.

### 3) اطبع الـ QR
1. افتح `qr.html` من نفس المكان اللي رفعت فيه الملفات.
2. هيتولّد QR Code تلقائيًا يشاور على صفحة الحجز.
3. اضغط **🖨️ طباعة الـ QR** وحطّه عند مدخل العيادة.

## 📦 شكل البيانات اللي هتوصل لـ n8n

```json
{
  "event": "clinic_booking",
  "name": "محمد أحمد",
  "phone": "01012345678",
  "date": "2026-11-20",
  "age": "30",
  "gender": "ذكر",
  "address": "القاهرة - مدينة نصر",
  "submittedAt": "20 نوفمبر 2026، 2:30 م",
  "source": "QR-Code"
}
```

في الـ workflow بتاعك: البيانات هتلاقيها في `{{ $json.body }}`
(مثلًا الاسم: `{{ $json.body.name }}`) ← وصلها بنود Excel بتاعتك.

## ✅ اختبار سريع

1. ضع رابط n8n الحقيقي في `app.js` وارفع الملفات.
2. افتح صفحة الحجز من الموبايل، املأ البيانات، واضغط تأكيد.
3. هتظهر شاشة "تم استلام حجزك بنجاح" — راجع تنفيذ الـ workflow في n8n (Executions).
4. لو ظهرت "حصلت مشكلة في الإرسال": غالبًا السبب رابط الـ Webhook غلط أو **CORS مش مفعّل**.
